# رزمة — إدارة المطبعة

هذا المستودع لا يحتوي على كود. يُستخدم فقط لنشر ملفات تنصيب برنامج «رزمة»، ويقرأ منه البرنامج التحديثات تلقائياً.

## التنصيب لأول مرة

1. افتح صفحة [الإصدارات](../../releases/latest) ونزّل الملف `ruzma-setup-….exe`.
2. شغّل الملف. إذا ظهرت رسالة «Windows protected your PC»، اضغط «More info» ثم «Run anyway».
3. بعد ذلك تصل التحديثات الجديدة تلقائياً من داخل البرنامج.

بيانات المحل تبقى على جهاز المحل فقط، ولا يُرفع منها شيء إلى هنا.
